# 比赛答辩代码入口

为避免逐行注释破坏 Python、SQL、提示词和 HTML 模板，本目录中的运行源码保持原样。完整中文逐行讲解位于：

- `docs/比赛答辩_scripts代码速查/README.md`：按技术主题导航。
- `docs/比赛答辩_scripts代码速查/函数与接口索引.md`：按函数、类、Flask 路由检索。
- `docs/比赛答辩_scripts代码速查/全部脚本逐行注释.txt`：单文件全文搜索版。
- `docs/比赛答辩_scripts代码速查/逐文件/`：45 个脚本各自的逐行讲解。

比赛现场建议使用 VS Code 打开项目根目录：

1. 按 `Ctrl+P`，输入脚本名快速打开文件。
2. 按 `Ctrl+Shift+F`，搜索函数名、接口路径、数据库表名或技术关键词。
3. 需要逐行解释时，在全文搜索版中输入原始代码、函数名或行号。
4. 代码更新后执行以下命令刷新所有讲解：

```powershell
python devtools/generate_competition_code_guide.py
```

常用关键词：`TShark`、`Payload`、`POC`、`behavior window`、`fusion`、`LLM review`、`RAG`、`embedding`、`rerank`、`DeepSeek`、`firewall`、`situation`、`professional report`、`JWT`、`MySQL`。
