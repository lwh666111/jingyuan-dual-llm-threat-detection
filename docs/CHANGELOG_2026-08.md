# 2026-08 更新日志

## 2026-08-10 高级 RAG 知识库

- 将单表 SQLite FTS5 管理页升级为多知识库工作台。
- 新增 MySQL 元数据表：知识库、文档、切片、召回测试和评估样例。
- 新增 PDF、Word、PowerPoint、Excel、Markdown、JSON、JSONL、CSV 和 TXT 解析。
- 新增语义结构切片与固定长度切片，支持切片长度和重叠配置。
- 接入阿里云百炼 `text-embedding-v4`（1024 维）和 `qwen3-rerank`。
- 新增 LanceDB 向量召回、本地 BM25、RRF 融合与云端重排。
- 新增安全术语查询扩展与来源多样性约束，降低中英术语差异和单一文档重复切片对召回的影响。
- 新增文档状态、切片查看与编辑、重建向量、召回测试和测试历史。
- 新增可维护回归用例、批量回归运行、通过率、平均耗时、逐项失败原因与运行历史。
- 旧 `llm/rag/rag_knowledge.db` 自动只读迁移，不删除、不覆盖。
- 新检索链路同时接入单事件 LLM 研判与连续攻击态势重新研判。
- 云端配置缺失或请求失败时，单事件守护自动降级到旧 FTS5 检索。
- 新增 OWASP、MITRE ATT&CK、CISA KEV 权威知识导入脚本。
- 新增 `/api/v3/rag/*` 接口，保留全部 `/api/v2/rag/*` 兼容接口。
- 前端保留原深色安全主题，重构为表格总览、全屏详情和独立弹窗交互。
- 修复 Node Dashboard 未代理 `/api/v3/` 导致新接口返回 405 的问题。
- 新增安全事件、知识问答两种查询模式以及安全领域门控，普通请求、无关问题和随机字符串不再被强制匹配到攻击知识。
- 将知识片段得分统一标注为“重排匹配分”，明确其不是攻击概率或模型准确率，并展示向量、BM25、RRF 与重排分数诊断。
- 新增动态阈值、低置信拒答、无匹配原因和候选最高分展示，默认有效阈值提升至 `0.35`。
- 回归评估新增正负样本、期望 Top-K、Recall@K、MRR、拒答准确率和误召率，并记录每次运行配置快照。
- 新增目录扫描、端口扫描、暴力破解、账号锁定和正常流量边界知识，以及 12 条可重复导入的中英文评估样例。
