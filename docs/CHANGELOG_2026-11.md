# 2026-11 更新日志

## 攻击来源城市聚合

- 态势感知页面的“近 30 天 TOP10 攻击来源城市飞线图”改为按来源城市聚合与排序，不再按单个来源 IP 排名。
- 同一城市的攻击次数、最高风险、最新活动时间会合并展示，并保留该城市覆盖的来源 IP 数量。
- 历史数据补充逻辑同步按城市去重，保证飞线图与攻击来源城市 Top7 饼图使用相同的数据口径。
- 补充哈尔滨、黑龙江及多个常见来源城市坐标，避免地图有统计数据却无法绘制飞线。
- 前端标题、摘要和详情文案统一使用“来源城市”，消除“Top10 IP”与城市可视化之间的歧义。
