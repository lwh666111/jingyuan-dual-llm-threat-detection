# 智御安全行为检测与处置基线

本文档用于补足单请求漏洞知识与时间窗口行为检测之间的衔接。规则必须结合来源 IP、目标资产、时间窗口和请求结果，不允许仅凭一个关键词将正常访问判定为攻击。

## 目录扫描与路径枚举 Directory Scan / Directory Enumeration

目录扫描是同一来源在短时间内请求大量不同路径，以发现管理后台、备份文件、配置文件、源码仓库或未公开接口的侦察行为。可靠证据应同时包含：来源 IP 相同、时间窗口较短、唯一 URI 数量明显增加、404 或 403 比例异常，以及 `/.git`、`/.env`、`/admin`、备份后缀等敏感路径。单次 404、浏览器请求静态资源或正常站点爬取不能单独判定为目录扫描。

处置时应对同源请求按时间桶聚合，只生成一个可处置事件；记录路径数量、失败状态码比例、首末请求时间和代表性 URI。可采用速率限制、WAF 路径规则、隐藏管理入口、清理备份文件和封禁确认恶意的来源 IP。

## 端口扫描 Port Scan / Network Service Scanning

端口扫描表现为同一来源在较短时间内探测同一主机的多个 TCP/UDP 端口，或横向探测多个主机的同一端口。SYN 探测、连接失败密度、目标端口离散度和时间集中度构成主要证据。正常服务发现、监控探针和少量连接失败应通过资产白名单及频率阈值排除。

## 暴力破解 Brute Force

暴力破解要求在时间窗口内观察到同一来源或同一账号的大量认证失败，通常还伴随用户名枚举、密码快速变化或多个账号轮换。一次登录失败、用户输错密码后立即成功、健康检查均不得判定为暴力破解。建议记录失败次数、涉及账号数、来源数、成功与失败转换，并使用限速、渐进延迟、MFA、账号锁定和风险认证处置。

## 账号锁定 Account Lockout

账号锁定策略应按账号和来源分别累计失败次数，采用短时间窗口、渐进式延迟或临时锁定，避免永久锁定导致拒绝服务。管理员应配置安全的解锁流程、MFA、异常来源告警和审计日志。锁定阈值需要结合真实用户误输率通过回归数据调整，不能把一次失败当作攻击。

## 正常流量边界

以下情况默认视为正常或仅保留原始日志：成功返回的普通页面访问、静态资源 200/304、一次认证失败、单个不存在路径、低频合法 API 调用。只有检测模型、POC 证据或行为窗口给出可复核攻击特征时，才允许进入 RAG 研判；RAG 的匹配分只能表示知识片段相关性，不能代替攻击概率。

参考依据：OWASP Authentication Cheat Sheet、OWASP Logging Cheat Sheet、MITRE ATT&CK T1046 Network Service Discovery。
